# BREAKER — Physics Siege & P2P Arena

브라우저에서 별도 빌드나 백엔드 서버 없이 동작하는 2D 물리 공성 아레나입니다. `Matter.js` 강체 물리와 `PeerJS` WebRTC 데이터 채널을 사용해 싱글 구조물 철거 퍼즐, AI 전차 공성전, 방 코드 기반 실시간 P2P 대전, 성채 맵 에디터를 하나의 웹 앱으로 묶었습니다.

## 바로 실행

- 웹 플레이: https://stickmongus.github.io/siege-arena/
- 초대 링크 접속: `https://stickmongus.github.io/siege-arena/?room=4자리코드`

## 게임 모드

- **싱글 철거 퍼즐 (6 스테이지)**: 제한된 탄약으로 기둥 절단, 폭발 드럼통 연쇄 유폭, 반발 패드 도탄, 블랙홀 중력장 추출을 활용해 적 코어를 모두 파괴하는 퍼즐 모드입니다.
- **AI 공성전 (3개 아레나 + 커스텀 맵)**: 탄도 궤적을 계산해 사격·회피하는 AI 전차와 부유섬 위에서 실시간으로 교전합니다. 상대 전차 또는 상대 진영의 에너지 코어를 파괴하거나 절벽 아래로 떨어뜨리면 승리합니다.
- **P2P 방 코드 대전**: 호스트가 발급한 4자리 숫자 코드(또는 초대 링크)로 두 브라우저가 직접 연결됩니다. 호스트가 물리 시뮬레이션을 수행하고 상태 스냅샷을 동기화해 양쪽 화면에서 동일한 지형 붕괴가 일어납니다. 에디터에서 만든 커스텀 맵으로도 바로 대전할 수 있습니다.
- **성채 맵 에디터**: 7종 블록(목재, 석재, 강철, 폭발 드럼통, 반발 패드, 에너지 코어, 기반암)을 격자 스냅과 좌우 대칭 모드로 배치하고, URL 또는 문자열 코드로 내보내거나 불러올 수 있습니다.

## 탄종 및 특수 기믹

| 슬롯 | 탄종 | 특징 및 우클릭(또는 `Space` / `E`) 공중 기폭 동작 |
| :---: | :--- | :--- |
| `1` | 철갑탄 | 빠른 탄속과 높은 단일 관통력·넉백 |
| `2` | 고폭 파편탄 | 넓은 반경 폭발. 비행 중 기폭 시 공중 폭발과 함께 하방 자탄 4발 산탄 |
| `3` | 블랙홀 중력탄 | 착탄 또는 공중 기폭 지점에 약 2.1초간 중력장을 열어 주변 블록·코어·전차를 끌어당긴 뒤 붕괴 폭발 |
| `4` | 지진 파쇄탄 | 강철 장갑에도 높은 피해를 주는 충격파 생성. 비행 중 기폭 시 수직 급강하 타격 |

## 프로젝트 구조

```text
├── index.html          # 시맨틱 레이아웃, HUD, 스테이지/P2P/공유 모달
├── styles.css          # 디자인 토큰 및 반응형 스타일
└── src/
    ├── main.js         # 모드 전환, 입력 바인딩, HUD 및 P2P 루프 제어
    ├── physics.js      # Matter.js 강체 시뮬레이션, 탄종/중력장 처리, 스냅샷 직렬화, 캔버스 렌더러
    ├── stages.js       # 싱글 6스테이지, 대전 아레나 3종, URL-safe Base64 맵 코덱
    ├── ai.js           # 탄도 샘플링 및 회피 기동 AI
    ├── net.js          # PeerJS 기반 4자리 방 코드 호스트/게스트 연결 관리
    ├── editor.js       # 격자 스냅·좌우 대칭 성채 에디터
    └── audio.js        # Web Audio API 절차적 효과음 합성기 (외부 오디오 에셋 없음)
```
